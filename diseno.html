Arquitectura del Prototipo

Este dispositivo inteligente y programable está diseñado para monitorear de forma continua la temperatura ambiental y del agua mediante sensores especializados. Al detectar umbrales críticos, el sistema activa automáticamente una bomba que recircula el agua desde el estanque geotérmico hacia las tuberías, aprovechando la inercia térmica del suelo (4-8°C a 1.8m de profundidad) para prevenir el congelamiento.

Unidad de Control e Intercambio

El sistema es portátil e instalable en exteriores, diseñado para conectarse a la red eléctrica domiciliaria (220Vac). Para garantizar la continuidad operativa ante cortes de suministro, cuenta con un banco de respaldo de baterías (UPS - AGM).
