Resumen del proyecto e investigación

El presente estudio describe el desarrollo experimental de un sistema diseñado para evitar el congelamiento de cañerías en zonas de bajas temperaturas, replicando escenarios térmicos representativos de dichas zonas[cite: 3, 4]. El objetivo principal fue evaluar el comportamiento de un sistema de recirculación utilizando el calor del suelo como mecanismo de mitigación[cite: 6].

La investigación incluyó una instrumentación completa para el monitoreo de variables térmicas e hidráulicas, operando de manera continua durante 45 días bajo condiciones controladas de laboratorio[cite: 53, 63]. Se evaluaron diversos materiales de tubería, incluyendo VALCO, HDPE, PPR, PVC y Cobre, para observar su comportamiento bajo las mismas condiciones de estrés térmico[cite: 16, 111].
